## Key Visual Features

### Desktop (>1024px)
1. **60/40 Split:** Left column wider for CTAs, right column for identity
2. **Vertical Border:** Thin white border (8% opacity) separates columns
3. **Alignment:** Identity text vertically centered in right column
4. **Sub-CTAs:** Two-column grid inside left column (Get insights | Let's talk)
5. **Consistent Background:** Dark #111 throughout

### Mobile (<768px)
1. **Vertical Stack:** All sections stack naturally
2. **Priority Order:** CTAs first, identity second, nav links third
3. **Border Separators:** Horizontal borders between sections
4. **Touch-Friendly:** Full-width buttons and links
5. **Readable Text:** Adequate spacing and contrast

## Color Palette

- **Background:** `#111` (dark charcoal)
- **Primary Text:** `#E4E2D8` (warm white)
- **Secondary Text:** `white/85` (85% opacity white)
- **Muted Text:** `white/60` (60% opacity white)
- **Accent (CTA):** `#FF5233` (orange-red)
- **Borders:** `white/[0.08]` (8% opacity white)

## Typography Hierarchy

- **Main Heading:** 3xl → 4xl (Build something useful...)
- **Identity Heading:** 2xl → 32px (who we are)
- **Eyebrow:** xs uppercase (Ready to work together?)
- **Body Text:** base → 18px (Identity paragraph)
- **Sub-CTA Titles:** base (Get insights, Let's talk)
- **Links:** sm (Footer navigation)

## Interaction States

- **Primary CTA:** Orange background, hover darkens to `#E64A2E`
- **Secondary CTA:** White border, hover increases opacity to 35%
- **Text Links:** White/80 → Orange on hover
- **Social Icons:** White/40 → White on hover

## Spacing System

- **Section Padding:** py-12 (mobile) → py-14/py-16/py-20 (desktop)
- **Horizontal Padding:** px-6 (mobile) → px-8/px-16 (desktop)
- **Button Gap:** gap-3 (12px)
- **Grid Gap:** gap-0 (borders handle spacing)
